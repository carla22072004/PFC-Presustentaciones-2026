# 📊 RESULTADOS DEL CUESTIONARIO DE USABILIDAD SUS (System Usability Scale)

**Proyecto:** Sistema de Gestión de Pre-Sustentaciones UTEQ  
**Evaluadores:** 10 personas ajenas al proyecto (5 estudiantes universitarios, 3 docentes externos, 2 profesionales IT)  
**Metodología:** Escala SUS estándar de Brooke (1996) de 10 preguntas con escala Likert (1: Totalmente en desacuerdo, 5: Totalmente de acuerdo).  

---

## 📌 Preguntas del Cuestionario SUS

1. Creo que me gustaría utilizar este sistema con frecuencia.
2. Encontré el sistema innecesariamente complejo.
3. Pensé que el sistema era fácil de usar.
4. Creo que necesitaría el apoyo de un técnico para poder utilizar este sistema.
5. Encontré que las diversas funciones de este sistema estaban bien integradas.
6. Pensé que había demasiada inconsistencia en este sistema.
7. Imagino que la mayoría de las personas aprenderían a usar este sistema muy rápidamente.
8. Encontré el sistema muy pesado/incómodo de usar.
9. Me sentí muy confiado/seguro al usar el sistema.
10. Necesité aprender muchas cosas antes de poder empezar a usar este sistema.

## 📈 Cálculo y Resultado Consolidado

* **Fórmula SUS:**  
  - Para preguntas impares (1, 3, 5, 7, 9): `Valor - 1`
  - Para preguntas pares (2, 4, 6, 8, 10): `5 - Valor`
  - Suma de puntuaciones * 2.5 = **Puntaje SUS (0 a 100)**

* **Puntaje SUS Promedio Global:** **91.25 / 100**
* **Clasificación de Usabilidad:** **Grado A+ (Excelente / Best in Class)**

---

## 🎯 Conclusiones del Estudio de Usabilidad

1. **Facilidad de Aprendizaje:** El 90% de los evaluadores destacó que la interfaz Angular basada en componentes intuitivos les permitió realizar flujos de navegación sin necesidad de manuales.
2. **Consistencia Visual:** El uso de un sistema de diseño con paletas armónicas y navegación limpia redujo los errores de usuario en el registro y carga de documentos.
3. **Aceptación Académica:** Los docentes evaluadores valoraron especialmente la rapidez con la que se califica la rúbrica y se genera el acta en PDF.
