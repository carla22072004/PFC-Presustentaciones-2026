# HU-01: Autenticación segura (RF-01)

**Prioridad MoSCoW:** Must

## Formato Connextra
> Como **usuario del sistema** (Estudiante, Docente, Coordinador o Administrador),
> quiero **iniciar sesión con mi correo institucional y contraseña**,
> para **acceder a las funcionalidades correspondientes a mi rol de forma segura**.

## Criterios de aceptación (Gherkin)

```gherkin
Feature: Autenticación segura
  Scenario: Login exitoso con credenciales válidas
    Given un usuario registrado con email "admin@uteq.edu.ec" y contraseña "admin123"
    When envía POST /api/v1/auth/login con esas credenciales
    Then el sistema responde 200 OK
    And el cuerpo de la respuesta incluye un token JWT con 7 claims (jti, iss, sub, aud, iat, nbf, exp)
    And se emite un refresh token asociado

  Scenario: Login con credenciales inválidas
    Given un usuario con contraseña incorrecta
    When envía POST /api/v1/auth/login
    Then el sistema responde con un código de error (401/403), nunca 200

  Scenario: Rate limiting ante intentos repetidos
    Given más de 6 intentos de login fallidos en 60 segundos desde el mismo origen
    When se realiza un intento adicional
    Then el sistema responde 429 Too Many Requests
```
