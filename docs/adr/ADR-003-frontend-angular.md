# ADR-003: Selección del Framework Frontend (Angular 17 SPA)

**Estado:** Aceptado  
**Fecha:** 2026-07-22  
**Decisores:** Equipo Frontend UTEQ  

## Contexto
Se requiere una interfaz de usuario reactiva, accesible y de diseño moderno para estudiantes, docentes y coordinadores académicos.

## Decisión
Utilizar el framework empresarial Angular 17 en modalidad SPA (Single Page Application) estructurado por módulos funcionales y estilizado mediante CSS Vanilla avanzado y arquitectura BEM.

## Consecuencias
- **Positivas:** Tipado fuerte con TypeScript; estructura modular escalable; excelente integración con RxJS y interceptores HTTP para tokens JWT; puntajes Lighthouse >= 90.
- **Negativas:** Curva de aprendizaje inicial mayor comparada con frameworks ligeros.
